# Oragenball AI Engine

Motor inicial de estatísticas para o Oragenball Dreams.

## Objetivo

Ler estatísticas de jogadores a partir de um CSV e gerar automaticamente relatórios em JSON e Markdown para serem usados no site.

## Fluxo

CSV → Python → JSON/Markdown → Next.js

1. Atualizar o ficheiro:
